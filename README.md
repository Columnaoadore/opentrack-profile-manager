## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Profile Library** | Store named opentrack configs per simulator or game |
| **Curve Editor** | Visual editor for response curves instead of raw config editing |
| **Filter Settings** | Adjust smoothing filter parameters per profile |
| **Quick Switch** | Apply any saved profile from the system tray without opening opentrack |
